A modern, responsive Single Page Application (SPA) built with React, consuming the public Fake Store API, featuring product listing, product details, cart flow, checkout, caching, and clean app structure.

This project follows the functional requirements, constraints, and expectations mentioned in the assignment PDF.

🚀 Tech Stack

React (Vite)

React Router – SPA client-side routing

Zustand – global cart state (lightweight alternative to Redux Toolkit)

Custom Hooks – data fetching + caching

Tailwind CSS – fast styling

Fake Store API – product data

LocalStorage – caching + cart persistence

🧩 Key Design Decisions
1. Custom Hooks for Fetching

To avoid “fetching inside components,” all data logic lives inside:

useProducts()
useProduct(id)
useCategories()


Each handles:

Fetching

LocalStorage caching

Loading/error states

2. Zustand for Cart

Chosen over Redux Toolkit because:

Less boilerplate

Faster to implement

Perfect for small apps

Still global and predictable

3. Two-Level Caching

In-memory for fast revisits

LocalStorage to persist across refresh
Improves perceived performance and reduces API load.

4. SPA Routing

Using React Router:

/
product/:id
/cart
/checkout

5. Edge Cases Covered

API failures

Loading placeholders

Empty search results

Product not found

Invalid quantity

Empty cart

Form validation

Offline-safe cached content
